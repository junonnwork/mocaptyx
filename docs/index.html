02 / RETARGETING

ライブも録画も、
モデルにフィット。

キャラクターの骨格・体型に合わせて、
動きを自動リターゲット。
脚の長さ、腰の高さ、足の接地を補正し、
必要に応じて微調整できます。

映像は録画モーションの比較です。左の灰色が元モーション、右の青がリターゲット後の骨格。約20秒・等速・音声なし。

配布モーションを試す ↗

03 / SIDE BY SIDE

同じ動き、
ふたつの解き方。

左はライブと同じ解き方。
右は録画を書き出すときの解き方。
開発版の比較映像を、そのまま並べて見られます。

映像は開発時点の一例です。速度・精度は収録条件やPC構成で変わります。リアルタイムの処理速度を測定した映像ではありません。
