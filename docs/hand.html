HAND OPTION · BETA

手指オプション。

指ごとの小さなIMU基板で、指の曲げと開きを測る手袋です。
基板データ・ファーム・アプリをまとめて公開します。自分で作って、自分のアバターの指を動かせます。

HandCapture v0.5 β ・ 1指1IMU版
β版です

実際に組んで動かしている段階の版です。精度や使い勝手は、これから改善します。特に電池の極性（4章）は、作る前に必ず読んでください。

01できること

  • 5本の指それぞれの付け根の曲げと開き、親指の動きを測ります。第2・第3関節は、付け根の曲がりから自然な曲がり方で推定します。
  • 出力：VMC（MOCAPTYX Stageで確認済み。Warudo、VSeeFaceなどにも）。VRChat OSCとOpenGloves（SteamVR）は、アプリには入っていますがまだ実機で確認していません。
  • 200 Hzで測り、USBドングルかWi-FiでPCへ。両手同時に使えます。キャリブレーションも両手まとめてできます。
  • 精度の目安（当方の実測）：手を返したり振ったりしている間の指の角度のブレは約2〜4°。
  • アプリからボタン1つでファームを書き込めます（開発ツールは不要）。

メイン基板（50×38 mm）。上の辺：I＝人差し指、M＝中指、R＝薬指、L＝小指（Left ではなく Little）。左右：THUMB R / THUMB L（中でつながっていて、親指と手の甲をどちらに挿してもよい）。

技適（電波法）について

メイン基板は、技適を取得済みの ESP32-S3-MINI-1 モジュール（工事設計認証 R 201-230385）を、内蔵アンテナのまま使います。モジュールの改造、アンテナの変更、電波の設定（出力・チャンネルなど）を変えたファームの書き込みをすると、日本国内では使えなくなります。ドングルも技適マーク付きのボードを使ってください。技適のないボードを日本国内で電波を出して使うことはできません。手袋やキットを販売する場合は、販売する方が表示などの義務を負います（利用条件をご覧ください）。

03基板の発注（JLCPCB）

ダウンロードの「基板データ」に、JLCPCB用のガーバー（zip）、部品表（BOM）、部品配置（CPL）が入っています。

メイン基板

  • 2層、50×38 mm、厚さ1.0 mm。部品実装（PCBA）は片面（表）。
  • ESP32-S3-MINI-1、TCA9548A、MCP73831など、すべてLCSCの部品番号つき。

IMU小基板（パネル）

  • パネル 93.0×37.6 mm（2列×6枚）、2層、厚さ0.8 mm、「Panel by Customer」。
  • センサー（ICM-42670-P）がJLCのStandard PCBA専用部品のため、Economicでは発注できません。表面処理はHASLで可。
  • 12枚とも同じ銅箔で、部品配置ファイルが「指用はR1、手の甲用はR2」を載せ分けます。備考欄に次の英文を書いてください：
    One design repeated 12 times in a customer panel. R1 or R2 is placed per board as listed in the CPL (boards 1–10: R1, boards 11–12: R2); the unlisted resistor pads stay empty.
  • 当方の注文例：2パネル（両手2セットぶん）で約22,000円（Standard PCBA、2026年10月）。
ヒント

JLCから「切り離しタブをコネクタ側にも付けてよいか」と聞かれることがあります。コネクタの辺は避けてもらうよう返信してください。

04電池（重要）

必ず読んでください

メイン基板v0.1の電池コネクタ（J2）は「1番ピン＝＋」です。市販のLiPo（Adafruit式）の多くは逆です。この基板には逆接続の保護がありません。逆に挿すと一瞬で壊れます。

  1. 電池は「JST PH 2.0・1番ピン＝＋（赤線）」の向きのものを選びます。商品の写真や説明で、線の向きを確かめてから買ってください。
  2. 基板のJ2の横に「＋」の印があります。挿す前に、赤い線が「＋」側に来るか目で確認します（テスターがあればなお安心）。
  3. 逆向きなら挿さないでください。正しい向きの電池を用意するまでは、USB給電で使えます（全部の機能が使えます）。

次の版の基板で、市販の向きに合わせて逆接続の保護も付けます。

05組み立て

  1. 小基板を外す：裏面に「F 0x68」（指用）、「H 0x69」（手の甲用）と書いてあります。縁を持ってタブの所で折り、出っぱりをヤスリで整えます。チップ（黒い四角）は押さないでください。手の甲用Hは、表にも油性ペンで印を付けておくと便利です。
  2. ケーブルをつなぐ：両端とも青い補強板を上にして差し込み、黒いレバーをパチッと倒します。基板はどれも部品面を外側に。片方だけ裏返すとケーブルがねじれ、電源とGNDが入れ替わって壊れます。
  3. コネクタの割り当て：I＝人差し指、M＝中指、R＝薬指、L＝小指。親指と手の甲Hは THUMB R / THUMB L のどちらでも（右手なら親指をTHUMB R、左手ならTHUMB Lにすると取り回しが楽）。
    左手では指の並びと I〜L の並びが逆なので、ケーブルが基板の上で交差します（問題ありません）。
  4. 手袋に付ける：指用は各指の付け根の骨（基節骨）の甲側、親指は親指の基節骨、Hは手の甲の真ん中、メイン基板は手首寄り。向きは適当で大丈夫です（キャリブレーションで測ります）。2か所ずつしっかり固定し、ケーブルも指の付け根あたりで留めます。基板がぐらつくと精度が落ちます。

06ファームの書き込み

  1. HandCaptureを起動します（ダウンロードしたzipを展開して HandCapture.exe）。
  2. メイン基板のスライドスイッチをONにして、USBでPCにつなぎます。OFFだと充電だけで起動しません。
  3. 左の「ファーム書き込み」にポートが出たら「手袋に書き込む」。約15秒、終わるまでUSBを抜かないでください。
  4. ドングルにするボード（AtomS3 Liteなど）も同じパネルで「ドングルにする」。

書き込めないときは、基板のボタン（BOOT）を押したままUSBを挿し直して、もう一度。

07PCとつなぐ

USBドングル（おすすめ）

ドングルをPCに挿したまま、手袋のスイッチを入れます。手袋は電源を入れたときにドングルを探すので、順番が逆なら手袋のスイッチを入れ直してください。

Wi-Fi

手袋はWi-Fiを設定していないと「HandCap-xxxx」という設定用の電波を出します（パスワード handcap1）。スマホでつないで http://192.168.4.1 を開き、家のWi-Fi（2.4 GHz）を設定します。PCと同じネットワークにしてください。

つながると、アプリの一覧に手袋が出ます。カードで右／左を選び、「センサー」で指を1本ずつ動かして、同じ指のバーが伸びるか確認します。

08キャリブレーション

カードの「キャリブレーション」（2台なら一覧の下の「両手まとめてキャリブレーション」）。画面の指示どおり約20秒です。

  1. 平らに置く：手のひらを下にして、机の上で指をそろえて伸ばし、動かさない。
  2. 手のひらを返す：指をそろえてまっすぐ伸ばしたまま、手を浮かせて、ゆっくり手のひらを上に向けて戻す（2回）。ここで指が曲がったり揺れたりすると精度が落ちます（警告が出たらやり直し）。
  3. 指を曲げる：ゆっくり指を曲げて伸ばす（2回、親指も一緒に）。
  4. もう一度平らに置く。

起動のたびと、ずれてきたと感じたときは、手を平らに置いて「合わせ直し」（基板のボタンでも同じ）。

09アバターへの出力

  • VMC：「出力」タブで送り先（例：127.0.0.1:39539）を設定。MOCAPTYX Stageで確認済みです。Warudo、VSeeFaceなどVMCを受け取れるアプリでも動くはずです。
  • VRChat OSC（未検証）：パー・グー・ピースなど8つのジェスチャーを HandCapGestureL/R などのパラメーターで送ります。
  • OpenGloves（未検証）：SteamVRのOpenGlovesドライバーへ指の曲げと開きを送ります。
  • 「アバター調整」タブで、アバターごとに曲げの強さや開きを調整して保存できます。

10うまくいかないとき

症状確認すること
USBでつないでもPCに出てこないスイッチがON か。データ通信できるUSBケーブルか。
手袋が一覧に出ないドングルを挿してから手袋のスイッチを入れたか。Wi-FiならPCと同じ2.4 GHzのネットワークか。
「センサーの値が止まっています」と出る電源を切って、その基板とケーブルを挿し直す。それでも出るなら小基板の不良の可能性（予備に交換）。
違う指が動くコネクタの割り当て（I・M・R・L）とケーブルを確認。
手を返すと指が開く・ずれるキャリブレーションの2つ目を、指をまっすぐのまま大きく返してやり直す。基板とケーブルがしっかり固定されているか。
キャリブレーションで警告が出る警告に書かれたステップの動きを、ゆっくり大きくしてやり直す。

うまくいかないときは、カードの「● 録画」で数十秒録って、Issuesに添えてもらえると原因を調べやすくなります（保存先は app\hand_capture\recordings）。

11v0.5の既知の問題と今後

  • 電池コネクタの極性が市販品と逆、逆接続の保護なし（4章）。
  • 左手でケーブルが基板上で交差する。
  • 親指は、ほかの指より動きが不安定です。
  • ケースは未公開（設計中）。
  • アプリの画面は日本語のみ。
  • VRChat OSCとOpenGlovesへの出力は、まだ実機で確認していません。試した方はIssuesで教えてもらえると助かります。

今後の予定

  • 1指2IMU版を検討中：指の第2関節の上（中節骨）にもIMUを足して、かぎ爪のような曲げも推定ではなく直接測る版です。今の1指1IMU版は、第2・第3関節を付け根の曲がりから推定しています。
  • フレキシブル基板版も検討中：IMUと配線を1枚の薄いフレキ基板にまとめて、ケーブルなしで指に沿わせる版です。
  • メイン基板の次の版：電池の極性と逆接続の保護、左手用のコネクタ割り当て、小型化。
  • 6個のIMUの時刻合わせ、温度補正など、ファームとソフトでの精度向上。
